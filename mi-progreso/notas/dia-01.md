## Conceptos clave (con mis palabras)

El **modelo de interconexión de sistemas abiertos (OSI)** es un marco que describe las funciones de un sistema de red.

Capa 1: capa fisica
el como se obtienen señales de forma fisica como por ejemplo los cables 

Capa 2: capa de enlace de datos
esta capa  que se utiliza para comunicar 2 dispositivos en la red
